# Python code — ML/AI for Social Science short course

Python reproductions and the canonical Python pipelines behind the two decks
(`ML Primer` and `ML and Causal Inference`). Python is the workhorse: the Stata
(via python integration) and R (via reticulate) code call into the **same**
conda environment, `mlssshort`.

## Environment

Use the repo-root `environment.yml` (preferred) or `requirements.txt`:

```bash
conda env create -f environment.yml          # creates `mlssshort`
conda activate mlssshort
python -m ipykernel install --user --name mlssshort   # for notebooks
```

## Files

Scripts (`.py`) are the canonical scripted runs; notebooks (`.ipynb`) are
logical-cell mirrors for interactive use.

- **Predictive modeling / Day 1:** `401kDataValidationIllustration.ipynb`,
  `401kDataHDLMs.ipynb`, `401kDataTrees.ipynb`, `401kDataStacking.ipynb`,
  `401kDataNN.ipynb`, `401kDataBlackBoxInterpretation.ipynb` (SHAP),
  `RiboflavinExample.ipynb`, `xray_resnet_training.ipynb` (transfer learning).
  Illustrations: `BaggingSmoothingDemo.ipynb`, `BoostingIllustration.ipynb`.
- **DML / causal inference / Day 2:** `401kATE.py` (+ `401kATE_diagnostics.py`),
  `401kLATE.py`, `401kHTE.py` (heterogeneous effects), `ExampleMWDiD.ipynb`
  (DiD), `ExampleFEPLM.ipynb` (FE-PLM abortion/crime), `dube_sensitivity_plot.py`
  (monopsony sensitivity figure), `HDLMSim.py`, `InferenceOverviewSimExtended.py`
  (+ `_plots.py`), `DLfePLM_viz.py`.

See `../Map of Code to Material.md` for the full code → slide/figure → data map.

## Notes

- All scripts/notebooks use **relative paths** into `../Data/`; run with the
  working directory set to `Python code/` (or the project root for some).
- Some outputs (`Data/*.parquet`, `Data/*.dta`, figures in `../Slides/figures/`)
  are regenerated by these scripts.
